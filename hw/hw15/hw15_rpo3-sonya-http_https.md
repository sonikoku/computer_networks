### 1.0

1.	HTTP - HyperText Transfer Protocol, используется для передачи данных: веб-страниц, изображений, видео и других файлов. Связывает браузер на пк с веб-сервером.
2. HTTPS отличается от HTTP....буквой S!! Secure, то есть безопасный. HTTPS шифрует весь трафик с помощью SSL/TLS, защищая данные от перехвата.
3. Клиент-серверная модель - это архитектура сети с делением на отправляющего запрос (клиент) и отвечающего (сервер). Клиент - браузер, приложение, отправляет запросы на получение данных и услуг. А сервер обрабатывает эти запросы, отправляет нужную клиенту информацию и хранит данные.
4. Идемпотентность -  свойство операции, при котором многократное повторение одного и того же запроса приводит к одну и тому же результату. Например, повторный запрос на удаление объекта вернет тот же результат, не ломая систему.

### 1.1

HTTP-запрос

    POST /api/users HTTP/1.1
    Host: example.com
    Content-Type: application/json
    Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
    Content-Length: 58

    {"name": "Иван", "email": "ivan@mail.com"}

1.	Какой метод используется? 

POST. Он отправляет данные на сервер (обычно для создания новой записи).

2.	Какой путь (endpoint) запрашивается?

/api/users

3.	Какая версия HTTP?

HTTP/1.1

4.	Что означает заголовок Content-Type?

Заголовок указывает формат данных в данном случае тут JSON

5.	Что означает заголовок Authorization?

Он несет в себе токен пользователя, а сервер видит, что у пользователя есть права на запрошенное действие

6.	Где находится тело запроса?

Внизу запроса, после пустой строки. Тут тело - это {"name": "Иван", "email": "ivan@mail.com"}

HTTP-ответ

    HTTP/1.1 201 Created
    Content-Type: application/json
    Location: /api/users/42

    {"id": 42, "name": "Иван", "email": "ivan@mail.com"}

1.	Что означает статус-код 201?
201 Created - запрос выполнен успешно, на сервере создан новый объект

2.	Зачем нужен заголовок Location?
В нем находится адрес, путь только что созданного объекта

3.	Что находится в теле ответа?

Созданный сервером объект в формате JSON, содержащий данные пользователя и его ID.

### 1.2

HTTP-запрос получения списка всех товаров

    GET /api/productsforsleepy HTTP/1.1
    Host: IdidntSleepAllNightSoS.com
    Accept: application/json


HTTP-запрос Создания нового товара с именем "Ноутбук" и ценой 50000

    POST /api/productsforsleepy HTTP/1.1
    Host: IdidntSleepAllNightSoS.com
    Content-Type: application/json
    Content-Length: 46
    
    {"name": "Ноутбук", "price": 50000}


HTTP-запрос Удаления товара с id=7

    DELETE /api/productsforsleepy/7 HTTP/1.1
    Host: IdidntSleepAllNightSoS.com

HTTP-запрос Обновления товара с id=3 (изменить цену на 45000)

    PATCH /api/productsforsleepy/3 HTTP/1.1
    Host: IdidntSleepAllNightSoS.com
    Content-Type: application/json
    Content-Length: 17
    
    {"price": 45000}
