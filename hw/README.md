# Домашние задания по курсу "Компьютерные сети"

- hw01 5 примеров на разных уровнях модели OSI.
- hw02 Wireshark. Скриншот рабочего Wireshark.
- hw03 Схема MAC-адреса и схема соединения компьютеров через коммутатор.
- hw04 IPv4. Распределение 172.168 /24 IP адрес на подсети где 5 зданий с маршрутами и в каждом от 15 до 25 устройств.
- hw05 Сisco. Построить сеть в циско с 8 компьютерами 2 коммутаторами и 1 хабом.
- hw06 Сisco. Блокировка через брандмауэр.
- hw07 Решение задач по IP-адресации и маскам подсети.
- hw08 Сisco. Создание трёх схем.
- hw09 Сisco. Настройка третьей схемы (из hw08) с RIP.
- hw010 Конспект по презентации протокол DHCP
- hw011 Сisco. Настройка схемы сети с NAT/PAT.
- hw012 Сisco. Настройка DNS-сервера.
- hw013 Краткая выжимка из трёх презентаций по TCP и UDP.
- hw014 Wireshark. Скриншоты: 2 TCP с разными флагами и примером UDP-пакета.
- hw015 HTTP/HTTPS. Определения терминов, разбор запросов и ответов, составление HTTP-запросов.
